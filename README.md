# 🌿 Paradise Nursery Shopping Application

## 📖 Description
Yeh ek plant shopping application hai jisme users plants browse kar sakte hain aur cart mein add kar sakte hain.

## 🛠️ Technologies Used
- React
- Redux Toolkit
- Vite

## 🚀 Features
- Product listing with categories
- Add to cart functionality
- Cart management
- Total price calculation
